# perceived-vs-measured-stress

## python stress analysis investigating the correlation between self reported and sensor measured stress levels using physiological and behavioral data in python, work load correlations and physiological Features Analysis.

### Files Structure

- `main.py`: Entry point. Runs the full analysis pipeline.
- `data_cleaning.py`: Functions for filtering and standardization.

## How to Run

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run main.py
